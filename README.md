# Evidence-management-system

A Python-based Evidence Management System developed using Python, SQL, and SQLite.

The project demonstrates how a digital application can be used to record, organise, search, and manage evidence information associated with cases.

## About the Project

The Evidence Management System is a portfolio and learning project developed to strengthen my Python programming, database, SQL, and software-development skills.

The application provides a structured method for managing evidence records and demonstrates how software can support information management processes.

Each evidence record can contain information such as:

- Case number
- Evidence description
- Evidence category
- Responsible officer or custodian
- Date recorded
- Evidence status

The project also reflects my interest in combining software development with my academic background in Law and current studies in Policing.


## Features

The application can support:

- Add evidence records
- View evidence records
- Search for evidence
- Search by case number
- Update evidence information
- Delete evidence records
- Record storage locations
- Associate evidence with case numbers
- Record responsible personnel
- Track evidence status
- Validate user input
- Handle database errors
